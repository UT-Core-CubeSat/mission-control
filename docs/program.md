# Program years

## 2026–2027 — current

**Objective:** Telemetry from every satellite board transmitted by antenna and received at the ground station.

**Target date:** 2027-04-26

## Our target for UTXplore
We need to get comms up and running between the satellite and ground station by 2027-04-26. Telemetry from each board, including health and heartbeat information, needs to be sent by antenna from the satellite and received by the ground station.
## What we would also like to show
Ideally, we can show attitude and state as observed by the satellite while it is on an air bearing in a Helmholtz cage to demo the control system. This is an additional objective beyond the telemetry link.
